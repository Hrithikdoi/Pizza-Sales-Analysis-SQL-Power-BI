# Pizza Sales Analysis

This project is a pizza sales analysis using SQL and Power BI.

## Tools Used

- SQL Server
- Power BI
- Excel / CSV

## What I Did

- Calculated total revenue, total orders and total pizzas sold
- Analyzed daily and monthly sales trends
- Analyzed sales by pizza category and size
- Found top and bottom pizzas based on revenue
- Found top and bottom pizzas based on quantity and orders
- Created an interactive Power BI dashboard

## Files

- `pizza_sales.csv` – Dataset
- `Pizza_Sales_SQL_Queries.sql` – SQL queries
- `Pizza_sales_report.pbix` – Power BI dashboard

## Dashboard

Power BI dashboard showing pizza sales performance and key insights.
